📡 Mapeo de Protocolo gRPC (Taller)

RPC Tipo gRPC Propósito en el Taller Mensaje Request / Response
ListSongs Unary Obtiene lista de canciones JSON disponibles Empty -> SongList
CreateRoom Unary Genera sala aleatoria de 6 caracteres CreateRoomRequest -> Room
Control Unary Modo director (play, pause, restart) ControlRequest -> Room
Join Server Stream Flujo continuo de líneas y acordes en vivo JoinRequest -> stream SongEvent
Sync Bidireccional Pings periódicos y cálculo de menor RTT / offset stream ClockPing <-> stream ClockPong
